# Official FURS eDavki schemas

`Doh_KDVP_9.xsd`, `Doh_Div_3.xsd` and `EDP-Common-1.xsd` as published by FURS on the eDavki XML schema page,
supplied by the project owner and stored byte-for-byte (see `SHA256SUMS`). Do not edit them; when FURS publishes a
new version, add it, update `FormType` and the writers, and record the new checksums.
